# Personal Website

This is the personal website of Xuefei built with Vue 3 and Vite.

## Project Setup

### Prerequisites

- Node.js (version 14.x or later recommended)
- npm (usually comes with Node.js)

### Installation

1. Clone the repository:

```
git clone https://github.com/yourusername/your-repo-name.git
cd your-repo-name
```

2. Install dependencies:
```
npm install
```
## Development

To start the development server:

```agsl
npm run dev
```

This will start the Vite dev server. Open your browser and navigate to `http://localhost:5173` to view the site.

## Building for Production

To build the site for production:
```npm run build```

This will generate a `dist` folder with your compiled assets.

## Deployment

After building, you can deploy the `dist` folder to your preferred hosting platform.

## Technologies Used

- Vue 3
- Vite
